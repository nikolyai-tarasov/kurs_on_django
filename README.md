# Skymailings
## Описание:
 Skymailings - это Веб-сервис для создания своей базы клиентов.Для которой каждый пользователь, может составить 
 сообщение, в котором сможет описать свою идею, технологию или услугу предоставляемую своему клиенту. А с возможность
 создания рассылок определенным клиентам, пользователь может убрать с себя большую часть работы.
 ## Использование:
1.  В пакете "config" собраны основные настройки проекта это маршрутизация приложений в модуле "urls.py", а в модуле 
"settings.py" организована работа над основными настройками проекта: подключение базы данных, настройка почтового 
сервиса для отправки сообщений, настройка статических и медиа файлов используемых в проекте, настройка сервиса "Redis" 
для серверного и пользовательского кеширования.
2.  Пакет(приложение) "mailings" это часть проекта в котором заключена работа над такими моделями (модуль - "models.py"), как 
"Recipient" - создание объекта(клиента), "Message" - создание объекта(сообщение), "Newsletter" - создание объекта
(рассылка), "MailingAttempt" - создание объекта(статистики). В модуле "urls.py" организована маршрутизация для приложения.
Модуль "views.py" собрал в себе контроллеры для создания, редактирования, просмотра и удаления выше упомянутых объектов
моделей. В модуле "forms.py" созданы стилизованные формы валидации данных вводимых пользователями. Модуль "admin.py" 
отвечает за возможность создания моделей приложения из встроенной админ-панели предоставляемой Django.  В модуле 
"services.py" создана сервисный класс миксин для организации авторизации пользователей.
В пакете "templates" собраны все шаблоны приложения "mailings", а пакет "templatetags" хранит в себе модуль "my_tags", 
который отвечает за обработку медиа файлов в данном приложении.
3. Пакет(приложение) "users" сосредоточенно на создании пользователей(объекты класс "User"), валидации данных при создании 
пользователей, организации работы входа, выхода и регистрации в проекте, а также обеспеченье доступа или отказа от доступа 
к данным в зависимости прав пользователя.
